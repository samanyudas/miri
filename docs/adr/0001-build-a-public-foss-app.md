# Build a public FOSS app

Miri provides an app interface for a scrolling window manager and is intended for Sam's daily use.
Its native app interface is designed and will be built from the ground up for Miri.
It will be publicly released as free and open-source software.
Sam finds Paneru's existing interface insufficient, so the app interface is a core product requirement.
Miri bundles a Paneru-based engine and uses `GPL-3.0-or-later`.
The app uses SwiftUI settings with AppKit where needed.
